달잠 개인정보처리방침

시행일: 2026년 6월 6일

달잠(DALJAM)은 사용자의 수면 기록과 컨디션을 개인 기기 안에서 관리하도록 설계된 앱입니다. 달잠은 사용자가 허용한 범위 안에서만 데이터를 사용하며, 수면 인사이트는 통계적 경향을 보여주는 참고 정보입니다.

1. 수집 및 이용하는 정보

달잠은 앱 기능 제공을 위해 다음 정보를 사용할 수 있습니다.

  • 사용자가 앱에 직접 입력한 기상 후 컨디션, 태그, 메모, 설정값
  • 사용자가 HealthKit 권한을 허용한 경우 건강 앱의 수면 관련 데이터
  • 알림 제공을 위한 취침 시각, 기상 시각, 알림 설정

2. HealthKit 데이터

HealthKit 데이터는 사용자가 iOS 권한 화면에서 명시적으로 허용한 경우에만 접근합니다. 달잠은 수면 기록 분석과 앱 내 표시를 위해 필요한 범위에서만 HealthKit 데이터를 읽습니다.

3. 데이터 저장 방식

달잠의 주요 데이터는 사용자의 기기 안에 저장됩니다. 현재 달잠은 별도 서버 계정, 원격 동기화, 광고 추적을 운영하지 않습니다.

4. 제3자 제공

달잠은 사용자의 개인정보나 HealthKit 데이터를 판매하지 않으며, 광고 목적으로 제3자에게 제공하지 않습니다. 법령상 요구가 있는 경우를 제외하고 사용자의 동의 없이 외부에 제공하지 않습니다.

5. 알림

달잠은 사용자가 허용한 경우 취침 전 알림과 모닝 알람을 보낼 수 있습니다. 알림 권한은 iOS 설정에서 언제든 변경할 수 있습니다.

6. 데이터 삭제

사용자는 앱 내 삭제 기능 또는 iOS 앱 삭제를 통해 기기에 저장된 달잠 데이터를 삭제할 수 있습니다. HealthKit 원본 데이터는 Apple 건강 앱의 설정에서 관리할 수 있습니다.

7. 아동의 개인정보

달잠은 아동을 대상으로 개인정보를 의도적으로 수집하지 않습니다. 보호자가 관련 문제를 발견한 경우 지원 채널을 통해 문의해 주세요.

8. 변경

본 방침은 앱 기능, 법령, 운영 방식의 변경에 따라 수정될 수 있습니다. 중요한 변경이 있는 경우 앱 또는 본 페이지를 통해 안내합니다.

9. 문의

개인정보처리방침에 대한 문의는 달잠 지원 페이지 또는 GitHub 저장소 이슈를 통해 남겨 주세요.
